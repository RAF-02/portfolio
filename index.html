04 — Work

Selected work.

2025 · Three live builds

01

voxa

Voice-to-voice AI that runs entirely on your machine — you speak, it thinks, it answers out loud. No cloud, no API keys, nothing leaves your computer.

0 API keys · 0 cloud calls whisper.cpp · Qwen3-4B · Kokoro

Mic → whisper.cpp (STT) → Qwen3-4B (LLM) → Kokoro (TTS) → speaker. Three open-source models chained into one conversation, fully offline, with session memory. The models are the easy part — the hard part is the seams: streaming between stages, clean turn-taking, shaving latency until it feels like talking, not dictation. Every stage is modular — point the brain at Ollama, LM Studio or any OpenAI-compatible API and nothing else moves. One command installs the rest; you bring your own LLM.

whisper.cpp · Qwen3-4B · Kokoro · Python
02

Desk-Engine

Live GIF wallpapers for Windows in Electron — audited and tuned until the RAM stopped creeping.

~100 MB steady while animating Electron · Performance engineering

Electron has a reputation: a hundred-plus megabytes before you've drawn a pixel. I shipped with it anyway — then audited every process, timer, cache and compositing path so nothing spends RAM by default. GIFs play live behind your desktop icons, click-through and always-on-top, at ~100 MB steady. The lesson wasn't 'Electron is light.' It was: measure everything, and never let a framework spend your user's RAM unattended.

Electron · Chromium tuning · Windows shell
